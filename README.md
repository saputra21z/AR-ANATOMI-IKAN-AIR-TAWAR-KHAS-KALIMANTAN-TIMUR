# AR 3D Anatomi Ikan Air Tawar Khas Kalimantan Timur

Hendy Saputra 2109106120

## 1. Tentukan Lokasi Folder Project

- Pilih lokasi/drive di komputer tempat menyimpan project (misalnya `D:/UnityProjects`).

## 2. Clone Repository

- Buka Terminal / CMD / Git Bash, lalu jalankan perintah berikut:
  
```bash
cd D:/UnityProjects
git clone https://github.com/saputra21z/AR-ANATOMI-IKAN-AIR-TAWAR-KHAS-KALIMANTAN-TIMUR/
```

## 3. Buka di Unity Hub
- Jalankan Unity Hub.
- Klik Add Project.
- Arahkan ke folder hasil clone (D:/UnityProjects/nama-repo).

## 4. Pilih Versi Unity
- Gunakan versi Unity sesuai yang ada di file ProjectSettings/ProjectVersion.txt

## 5. Download Package Vuforia
- Download package vuforia yang ada pada link drive dibawah: 
[https://drive.google.com/drive/folders/14VKU9eoMusyO5V0uqwQyzU1Y56fiZ-rK?usp=sharing](https://developer.vuforia.com/downloads/sdk)
- Kemudian buka file package lalu hapus zip package lama kemudian ganti dengan zip package yang telah didownload tadi, ikuti arahan seperti pada gambar dibawah

- Klik project pada Unity Hub untuk membukanya di Unity Editor.
