## 1. Tentukan Lokasi Folder Project
Pilih lokasi/drive di komputer tempat menyimpan project (misalnya D:/UnityProjects).
## 2. Clone Repository
Buka Terminal / CMD / Git Bash, lalu jalankan perintah berikut:

cd D:/UnityProjects
git clone https://github.com/Klepon313/AR-3D-SARUNG/
## 3. Buka di Unity Hub
Jalankan Unity Hub
Klik Add Project
Arahkan ke folder hasil clone (D:/UnityProjects/nama-repo)
## 4. Pilih Versi Unity
Gunakan versi Unity sesuai yang ada di file ProjectSettings/ProjectVersion.txt
